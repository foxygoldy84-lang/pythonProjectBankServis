# Банковское приложение (Курсовая работа)

Комплексное Python-приложение для анализа и обработки финансовых транзакций, считываемых из файлов Excel. Проект разработан с использованием подходов функционального программирования, автоматического линтинга, форматирования кода и модульного тестирования.

## 🛠 Реализованный функционал

В соответствии с техническим заданием были выбраны и успешно реализованы следующие модули и сервисы:

1. **Веб-страницы — Страница «События» (`src/views.py`)**
   * Генерация JSON-ответов по гибким временным диапазонам (Неделя `W`, Месяц `M`, Год `Y`, Все данные `ALL`).
   * Расчет общих расходов с группировкой (Топ-7 категорий + «Остальное»).
   * Выделение блока «Переводы и наличные».
   * Интеграция со сторонними API (ЦБ РФ) для вывода актуальных курсов валют и базовой стоимости акций S&P 500.

2. **Сервисы — «Инвесткопилка» (`src/services.py`)**
   * Реализация логики накоплений через автоматическое округление трат по заданному пользователем порогу (10, 50 или 100 ₽).
   * Код написан с применением элементов **функционального программирования** (`filter`, `lambda`).

3. **Сервисы — «Простой поиск» (`src/services.py`)**
   * Переиспользованная и расширенная функция из прошлого проекта для регистронезависимого поиска операций по ключевым словам в категории или описании (на базе модуля `re`).

4. **Отчеты — «Траты по дням недели» (`src/reports.py`)**
   * Расчет среднего чека расходов в каждый из дней недели за последние 3 месяца от контрольной даты.
   * Реализован **кастомный декоратор** (адаптированный из прошлого проекта), который автоматически перехватывает ошибки и сохраняет сгенерированный отчет DataFrame в файл конфигурации `.csv`.

## 📂 Структура проекта

Код проекта строго декомпозирован и отделяет бизнес-логику от прямого получения данных из Excel:
* `src/utils.py` — утилиты для безопасного чтения таблиц, конфигураций и логирования процессов в `logs/utils.log`.
* `src/main.py` — главная точка входа, демонстрирующая работу всех подсистем приложения с автоматической подстройкой под контрольные даты исходного файла.
* `tests/` — изолированные модульные тесты.

## 🚀 Команды для управления проектом

В проекте используется менеджер зависимостей **Poetry** и настроен инструмент автоматизации задач **Poe the Poet**.

### 1. Автоматическое исправление стиля и проверка линтерами
Для комплексного форматирования кода (сортировка импортов, исправление отступов по PEP 8, бескомпромиссная чистка стилей через `black` и строгий контроль `flake8`) запустите в терминале одну общую команду:
```bash
poetry run poe fix
```

### 2. Запуск тестов
Для проверки работоспособности всех функций и расчетов изолированно от основного файла выполните команду тестирования:
```bash
poetry run pytest
```

### 3. Демонстрационный запуск приложения
Чтобы запустить главную демонстрационную логику обработки файла `data/operations.xlsx`, выполните:
```bash
poetry run python src/main.py
```
